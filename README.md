# 灵魂景观 Mindscape · AstrBot 插件

> **别人做的是让 bot 更能说。这个做的是让它知道什么时候别说。**

<img src="assets/demo-2-memory.png" width="600" alt="三天前的事它还记着">

## 先说清楚：它和「记忆插件」不是一个位置的产品

AstrBot 的记忆生态已经很成熟了 —— 有做完整记忆生命周期的，有上向量库做混合检索的，
有做人格演化的。**如果你要的是「最深的记忆」，建议直接用它们。**

灵魂景观补的是反方向的另一半：

| 别人在解决 | 这个在解决 |
|---|---|
| 让它记得更多 | 让它知道**哪一句别说** |
| 让它更会聊 | 让它**不出戏**（框架报错绝不发出去） |
| 让它更有人格 | 让它**分得清**这话是不是在跟它说 |
| 让它主动开口 | 让它**真的可以闭嘴** |

## 四个还没人占的位置

### ① 沉默权 —— 它真的可以什么都不发

框架总得把一条回复发出去，所以「没话说」只能**演**出来。
时间长了 bot 就开始说「（和我无关，安静飘过）」这种话 —— 说了话，还多一层出戏。

这个插件给它一个**沉默令牌**：不想说话时只输出一个标记，发送前整条回复被清空，
群里**没有任何消息**。

### ② 防出戏 —— 上游报错不会出现在群里

`LLM 响应错误: APITimeoutError` 这种东西发一次，人设就崩了。
拦在发送前：命中错误特征就整条清空，用户看到的只是「这次没说话」。
另有输出规范化（压平多段、去 AI 腔）和空回复救援。

### ③ 定向性判定 —— 分得清这话是不是在跟它说

有人 @ 别人，而那个人的昵称里恰好含 bot 的名字 —— 这就是误唤醒。
这个插件能分清「@ 我」「正文提到我」「@ 别人但昵称像我」「跟我无关」四种情形。

### ④ 自主冒泡 —— 不叫也会开口，而且不是整点

抽签制：把时间窗等分成 N 段、每段随机抽一分钟，种子按日期算。
**重启不会重新洗牌，错过的名额不补** —— 不会整点出现，也不会攒着一次性爆发。

## 附带的三层（不是主打，但都在）

- **认知层**：五层记忆装配（规矩 / 账本 / 风格 / 摘要 / 原文），带字数预算。
  刻意**不用向量库** —— 角色 bot 要的是「按时间发生的事」，不是「最相似的片段」。
  不认同这个取舍的话，上向量库的插件有很多。
- **表达层**：表情包采集（视觉模型判契合度）+ 按语境选图 + 斗图队形
- **运维**：配置独立于框架，自带桌面版（tkinter）与网页版管理界面

## 安装

**方式一：插件市场**（推荐）—— 搜索「**灵魂景观**」或「**mindscape**」

**方式二：手动**

```bash
cd AstrBot/data/plugins
git clone https://github.com/Illusory-moon/astrbot_plugin_mindscape.git
```

装好后启动日志里应该有：

```
[mindscape] 插件已加载（7 个模块）
```

## 配置

⚠️ **本插件不读 AstrBot 的插件配置页**，它读独立文件：

```
~/.mindscape/config.yaml          # 环境变量 MINDSCAPE_CONFIG 可改路径
```

这样同一份配置既能给插件用，也能给命令行脚本用。
完整示例见主仓库 [`config/config.example.yaml`](https://github.com/Illusory-moon/bot-mindscape/blob/main/config/config.example.yaml)。

```yaml
memory:
  max_chars: 2500              # 每轮注入的字数预算
  bots:
    - self_id: "你的botQQ"
      name: "bot名字"
      diary: "./data/bot-name.md"
      rules:
        - "被点名时必须回复"
```

## 哪些功能需要额外打补丁

**装完即用**：沉默权、防出戏、认知层、表达层。

**需要给 AstrBot 本体打补丁**：唤醒层的进阶策略 ——「提到名字必回」「自主冒泡」
「定向性判定」「每 bot 独立白名单」。原因是这些判定发生在框架的**消息分发阶段**，
比插件钩子更早，插件够不到。

补丁在主仓库 [`patches/`](https://github.com/Illusory-moon/bot-mindscape/tree/main/patches)，附自动安装脚本。
不打补丁也能用，只是唤醒策略退回 AstrBot 原生的「前缀 / @ 唤醒」。
